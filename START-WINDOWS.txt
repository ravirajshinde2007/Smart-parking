PARKSMART — SEQUENCE OF EXECUTION (WINDOWS GUIDE)
========================================================================

STEP 1: DATABASE SETUP (Run in MySQL Workbench)
------------------------------------------------------------------------
1. Open MySQL Workbench and connect to your MySQL Server (e.g. MySQL80).
2. Open and execute:
     backend/schema.sql
3. Open and execute:
     backend/seed.sql
4. Verify the database "parksmart" is created with tables:
   users, parking_lots, parking_slots, bookings, access_logs, payments, notifications.


STEP 2: ENVIRONMENT CONFIGURATION
------------------------------------------------------------------------
1. Copy backend/.env.example to backend/.env:
     copy backend\.env.example backend\.env
2. Open backend/.env in your text editor.
3. Update DB_PASSWORD with your actual MySQL password (e.g. root password).
   Optional: update JWT_SECRET with any secret key.


STEP 3: RUN THE APPLICATION
------------------------------------------------------------------------
You can run either the Express + Vanilla stack or the Next.js stack:

OPTION A: Express + Frontend (Default)
  Run from root folder:
     npm run dev:backend
  Or inside backend:
     cd backend
     npm run dev

  Open your browser:
     User App:     http://localhost:5000
     Admin Panel:  http://localhost:5000/admin
     Health Check: http://localhost:5000/api/health

OPTION B: Next.js 15 App Router (Modern React 19)
  Run from root folder:
     npm run dev

  Open your browser:
     User App:     http://localhost:3000
     Admin Panel:  http://localhost:3000/admin
     Health Check: http://localhost:3000/api/health

STEP 5: TROUBLESHOOTING
------------------------------------------------------------------------
- "Database unavailable" / "ECONNREFUSED":
  Ensure MySQL service (MySQL80) is running in Windows Services (services.msc).
- "Access denied for user 'root'@'localhost'":
  Check and update DB_PASSWORD in backend/.env.
- "ER_BAD_DB_ERROR":
  Make sure you ran backend/schema.sql in Step 1.
